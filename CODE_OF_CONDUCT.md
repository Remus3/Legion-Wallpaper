# Code of Conduct

This is a single-operator project published so other people can read and borrow
the process. The interaction surface is small, so this document is short and
says what is actually enforced rather than restating a template.

## The standard

Be accurate and be civil. In practice that means:

- **Bring evidence.** This repo's central rule is that a claim is not evidence.
  The same applies in an issue: cite the file, the line, the command you ran and
  the output you saw. "This is broken" without a reproduction is not a report.
- **Disagree about the work, not about the person.** Harassment, insults,
  demeaning or discriminatory remarks, sexual attention, and deliberate
  intimidation are not welcome here in any form.
- **Do not publish other people's private information**, including account
  names, home paths, personal addresses and machine layouts. This repository has
  automated guards against exactly that class of leak because it happened here
  (see `tests/test_no_split_identity.py`), and it applies to contributors as
  much as to the maintainer.
- **Respect the corpus boundary.** The images this pipeline restores are
  third-party illustrations. Do not post them, link scraped copies, or ask for
  them. See `README.md` and `docs/RESTORATION_PLAN.md` section 10.

## Scope

This applies to every space this project owns: issues, pull requests, code
review, commit and discussion text.

## Enforcement

The maintainer enforces this directly. Unacceptable content is edited or
deleted, and the account is blocked from the repository if it continues. There
is no committee and no appeal process, because there is one maintainer.

To report a problem, open an issue. If the report itself should not be public,
follow `SECURITY.md`, which describes the private channel.
